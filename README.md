# Mi perfil en GitHub Pages

Este ejemplo usa un solo archivo: `index.html`. Cada estudiante puede cambiar los textos sin instalar programas ni tocar los estilos.

## Para el estudiante: cambiar mi página

1. Abre `index.html` en tu repositorio y pulsa el ícono del lápiz (**Edit this file**).
2. Busca las notas `CAMBIA` dentro del archivo. Sustituye las iniciales, el nombre y las frases de ejemplo por tus propios textos. Conserva las partes entre `<` y `>`.
3. Pulsa **Commit changes** para guardar. Vuelve a abrir la dirección de tu página después de unos minutos y actualízala.

También puedes abrir `index.html` en un navegador antes de subirlo para ver cómo se ve.

**Consejo:** usa información que quieras compartir públicamente. No pongas tu dirección, teléfono ni otros datos privados.

## Mini actividad

- Cambia el nombre, la presentación, las tres tarjetas y la meta.
- Enseña la página publicada a un compañero.
- Haz un segundo cambio y comprueba que se actualizó la misma dirección.
